终端功率等级--
设备固件没有提供基带实测发射功率（PUSCH / PHR）接口，AT 工程模式也未返回可解析的功率字段。 此处数值按 3GPP 开环功控模型，由 RSRP 推算路径损耗后估算，仅用于观察趋势。 实际上行功率由基站通过 TPC 命令闭环控制，终端不能自行调高；擅自改动校准数据会影响合规与稳定性。
估算方法说明
路径损耗 PL ≈ 参考信号功率 − RSRP；估算发射功率 ≈ P0 + α·PL + 带宽与 MCS 修正，并限幅在终端功率等级上限内。因基站实际下发的 P0 / α / TPC 未知，结果为区间估算，不能作为测量值使用。

估算模型说明
基础 1.10 W ＋ 数据链路 0.50 W ＋ 吞吐加成（速率折算，≤1.20 W）＋ 功放加成（按估算发射功率分档，≤0.80 W）＋ 扫描 0.60 W。每次刷新用相邻两次采样的功率对时间积分，页面关闭期间按最后一次功率续算。
