# SY108 供电电容焊接指南（安卓 OTG 供电不稳的改装）

> **说明**：本文涉及的 PCB 结构（丝印 `Dorado_Y1.00_PCB`，SY108-658/688 同主板）来自公开拆解资料与魔改圈改装文章的整理。**本仓库不收录任何拆解图片**；焊接位置以文字描述 + 万用表实测定位（不依赖图片也能操作）。
>
> 系统本身属于 [jason-liu-4980/sy108-mainline](https://github.com/jason-liu-4980/sy108-mainline)，本文只是硬件改装笔记。

## 背景

5G 发射为脉冲大电流（峰值 1~2A+），安卓 OTG 口通常只给 500mA~900mA，供电不足时表现为"连上几秒就掉线"。在 USB-C 供电入口并一颗储能电容（削峰填谷）是社区标准解法；魔改圈原文：「若出现频繁重启，在主板 VCC 与 GND 点位焊一颗 10V 2200µF 电容即可解决」。

## 方案 A ★推荐：正面测试点（只开背盖，不动主板）

SY108 正面板（丝印 `Dorado_Y1.00_PCB`）上有金色测试点阵列（含 SIM 魔改飞线点位，丝印 `RST / CLK / VCC / IO / GND`），这些就是官方口径的"VCC 与 GND 点位"：

1. 拆开背盖露出正面板（不用动主板、不用开屏蔽罩）
2. 找到 USB-C 座附近的**金色圆点阵列**（约 15 个点）；右下角另有一片约 5×5 的密集方阵，同为可用点位
3. **万用表定位**（2 分钟，通电测量）：
   - 壳插 USB 通电，万用表直流 20V 档
   - 黑表笔碰 USB-C 银色金属壳 → GND
   - 红表笔逐个点测试点：读到 **~5V 的点 = 正极**；读 0V 导通的 = GND；1.8V/信号点跳变的别用
4. 拔电焊接：电容**长脚/白条侧 = 正极**接 5V 点，**短脚 = 负极**接 GND 点（负极直接搭 USB-C 金属壳更省事）

⚠️ 避坑：天线排线（黄色 FPC）上的金色圆点是**铆钉/天线触点，不是测试点**，不要焊。

## 方案 B（备选）：主板电源区 MLCC 电容阵列

需拆出主板开屏蔽罩，难装回，仅在方案 A 找不到 5V 点时考虑：

- 主板电源区有一排大颗贴片电容（MLCC 阵列，约 8~9 颗，紧邻 3 颗丝印 `Wayon QSSP02` 的 VBUS 开关管和 `UMP510G5` PMIC）
- 电解电容两脚搭焊在**任意一颗大贴片电容的两端**（即 VBUS 5V 与 GND）
- 极性：先用万用表确认（读到 ~5V 的那端为正极），反接会炸电容

## 电容选型

| 规格 | 评价 |
|---|---|
| **10V 1000µF 低 ESR 铝电解** | ✅ 最推荐档位（实测采用）：足够顶住发射脉冲，插拔浪涌小 |
| 10V 2200µF | 魔改圈常用；容量更大但上电浪涌大，个别手机会过流保护 |
| 470µF 以上 / 6.3V 以上 | 都可用；耐压 10V 更佳 |
| 2200µF 以上 | ❌ 不建议（插拔浪涌易触发手机过流保护） |

进阶：可再并一颗 10~100µF 陶瓷贴片滤高频毛刺（可选）。

## 焊接要领

1. 断电 5 分钟再焊；烙铁 300~350℃，每个焊点 ≤3 秒
2. 焊完量两脚不短路（电阻不为 0）
3. 先插电脑确认壳正常（`http://192.168.66.1/` 能打开），再插手机试 OTG
4. 用热熔胶/704 硅胶把电容固定好，防止震动疲劳开裂；确认合盖不压到电容

## 测试顺序

```
1. 插电脑（供电最稳）→ 确认壳正常开机、状态页能打开
2. 插安卓手机 OTG → 挂几分钟看还掉不掉线
3. 压力测试：跑一会儿测速（5G 大功率发射是最容易掉的场景）
```

若加电容后仍偶发掉线，再配一根 **OTG 供电 Y 线 + 充电宝**（数据连手机、电力独立供给），双管齐下基本彻底解决。
